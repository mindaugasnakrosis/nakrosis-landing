What I do

  1. Build AI agents

    Tool-using agents that do real work in production, not demos: event-driven triggers, a model picked per task, read-only by default, and a trace you can reconstruct the morning after. Claude API, MCP, Python.

  2. Move companies onto AI workflows

    Map how the work actually gets done, find the steps where an agent or a Claude Code skill beats a person, and ship them as shared tools the whole team uses. MCP servers over the company's own data, so the capability outlives any single project.

  3. Automate operations

    Incident triage, cloud cost review, backlog grooming, pre-merge review: repetitive senior-judgment work encoded once, with its sources cited, and run on demand.

  4. Lead the technology

    VP- and principal-level mandates: architecture, technology budget, hiring, ISO 27001, and translating between the CEO and the engineers.
